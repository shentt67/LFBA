## 三个必须记住的结论

1. **梯度不是特征**：LFBA 用“攻击端嵌入对损失的梯度”当作样本语义表示，代码变量是 `grad_vec_epoch`。
2. **毒化集只构建一次**：在 `ep == 1` 用第 0 轮梯度算余弦相似度得到，之后不再变化。
3. **每轮都会重写数据**：每一轮都从 `dataset.data_p`（干净快照）重新注入触发器并做切换，不会跨轮累积。
